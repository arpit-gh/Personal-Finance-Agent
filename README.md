# Personal-Finance-Agent

A banking assistant that answers balance questions, explains where the money went, and lets the user set a budget.

## Setup & Running

### 1. Install Dependencies

```bash
npm install
```

### 2. Create a .env file just like the .env.example file

paste your GROQ_API_KEY and MONGODB_RI

### 3. Run the seed script

```bash
npm run seed
```

### 4. Run your queries

```bash
npm run start
```
